# Stage 5: Prediction and Inference

## Objective

This stage loads the trained model and predicts the produce class and freshness from a new input image. It includes an unknown/unsupported handling rule based on confidence thresholding so the system does not force a prediction on arbitrary images.

## What this stage covers

- Validating uploaded image paths and extensions
- Preprocessing an input image to the model input size
- Running inference through the trained Keras model
- Reading the class mapping from classes.json
- Parsing labels such as apple_fresh or banana_rotten
- Returning an unknown result when confidence is too low

## Example usage

```bash
python ml/predict.py --image dataset/train/apple/apple_0.jpg --model-path ml/models/freshness_model.keras --class-config classes.json --threshold 0.55
```

## Output example

```json
{
  "produce": "Apple",
  "category": null,
  "freshness": "Fresh",
  "confidence": 0.943,
  "model_version": "v1.0",
  "message": "Prediction generated by the trained model.",
  "predicted_label": "apple_fresh"
}
```

## Unknown image handling

If the top predicted probability falls below the confidence threshold, the result is returned as:

```json
{
  "produce": null,
  "category": null,
  "freshness": "Unknown",
  "confidence": 0.21,
  "model_version": "v1.0",
  "message": "Unsupported or low-confidence image"
}
```

## Notes

This stage keeps the inference pipeline model-driven and avoids hard-coded color or image rules. The prediction always comes from the trained deep-learning model and a configured threshold.
